create\+\_\+supervised\+\_\+dataset.\+main (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Main entry point for creating hybrid anomaly labels. 

This script loads DBSCAN, EXAMM, and OC-\/\+SVM outputs and merges them by window index and filename to produce a unified hybrid anomaly label.

Hybrid labeling rules\+:
\begin{DoxyItemize}
\item {\bfseries{examm\+\_\+flag}} = 1 if EXAMM violation counts/severity exceed thresholds.
\item {\bfseries{ocsvm\+\_\+flag}} = 1 if OC-\/\+SVM score \texorpdfstring{$<$}{<} 0 (outlier).
\item {\bfseries{dbscan\+\_\+flag}} = 1 only if DBSCAN marks noise (-\/1) AND either EXAMM or OC-\/\+SVM agrees.
\item {\bfseries{hybrid\+\_\+label}} = 1 if any of the above flags activate.
\end{DoxyItemize}

The output CSV contains all merged fields and the new labels.
